# Project 2: Exploratory Data Analysis (EDA)
Analysis of the cleaned dataset from Project 1 to identify trends, outliers, and key statistics.

## Key Requirements
- Calculate basic statistics(mean, median , count)
- Identify trends and outliers 
- Summarize key observations 

## Key Findings 
- Chair is the best-selling product (562 units); Phone is the lowest (411 units)
- Payment methods are evenly distributed, with Online slightly leading (258 orders) 
- Cancelled orders are the most common status (-20.8%) - worth investigating 
- UnitPrice abd Quantity show no outliers; TotalPrice has some outliers above 2693.68 (max 3456.4) 

## Tools 
Excel (PivotTables, STDEV/MEAN/MEDIAN formulas, conditional formatting)
