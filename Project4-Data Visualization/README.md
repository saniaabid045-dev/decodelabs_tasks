# Project 4: Data Visualization

Created visualizations to communicate key insights from the sales data clearly and effectively.

## Key Requirements

- Created data visualizations using Bar, Pie, and Line charts
- Selected appropriate chart types based on the data and purpose
- Highlighted key insights and trends from the visualizations

## Key Visualizations & Findings

- Used a Bar Chart to compare product quantities and identify differences across products.
- Used a Pie Chart to show the proportional share of different payment methods.
- Used a Line Chart to visualize sales trends across months and identify changes over time.
- Added clear titles, labels, and explanations to make the visualizations easy to understand.

## Tools

Microsoft Excel

## Key Skills

Data Visualization, Excel Charts, Data Analysis, Data Storytelling
