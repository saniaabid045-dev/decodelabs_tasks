# Project 3: SQL Data Analysis
Used SQL queries to extract insights from a cleaned e-commerce dataset (1200 records) as part of the Data Analyst Internship at Decodelabs
## Key Requirements 
- Write SELECT queries 
- Use WHERE, ORDER BY, GROUP BY
- Perform basic aggregations (COUNT,SUM,AVG)
## Key Queries & Findings
- Retrieved and filtered order data by status (e.g., Cancelled orders)
- Sorted orders by UnitPrice to identify highest and lowest priced items 
- Grouped orders by Product to count total orders per product 
- Calculated total order count, total quantity sold, and average price across the dataset 
- Combined GROUP BY with SUM and AVG to find total quantity sold and average price per product - confirming Chair as the best-selling product (562 units), consistent with Project 2 findings 

## Tools 
SQLite (via SQLite Online), SQL fundamentals - querying, filtering, grouping
